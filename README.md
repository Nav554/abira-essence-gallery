# Abira Fragrances

Build a premium luxury perfume brand website for a Dubai-based fragrance company.

BRAND NAME:
ABIRA FRAGRANCE

Business Type:
Luxury Perfume Brand
(No Online Store)

Primary Goal:
Generate inquiries through WhatsApp, Phone Calls and Instagram.
No payment gateway.
No user login.
No cart.
No checkout.
No prices on individual products.
Only display:
"Starting from AED 35 to AED 100"

• Tailwind CSS

• TypeScript
• Lucide Icons
